# 工作量量化工具 V1 需求确认

## 1. 已确认意图

- 使用者：埃塞俄比亚办事处的一名管理者，集中录入所有人员的工作。
- 日常规模：约 10–30 条记录，以快速逐条录入为主。
- 运行方式：Windows 单机、完全离线、无需账号、无需 Python、无需 Office。
- 交付方式：首版为解压即用的便携目录，不制作安装向导。
- 语言：开发和首版界面使用中文；数据模型保留英文规则名称字段，便于后续英文版。
- 历史边界：不迁移现有 Excel 工作记录；Excel 只用于规则和初始化字典核对。

## 2. 当前最小可用版本

当前版本实现一个可实际试用的闭环：

1. 维护人员、小组、项目和定额规则；
2. 日期 → 人员 → 项目 → 模块 → 类别 → 子类型级联录入；
3. 根据规则自动换算标准化数量并用 Decimal 计算工作量；
4. 对有歧义的规则要求人工输入确认值和依据，不猜测业务口径；
5. 写入单一 SQLite 数据库并保存规则、人员、小组、项目快照；
6. 查询、编辑、作废历史记录；
7. 按日、按月导出 Excel，按月导出 AI 用 CSV/JSON；
8. 通过设置页备份数据库。

## 3. 验收流程

```text
设置中新增项目
→ 录入页立即出现该项目
→ 选择人员和规则
→ 输入实际数量
→ 自动预览标准化数量和工作量
→ 保存到 SQLite
→ 历史页可查询
→ 可导出 Excel
```

规则修改后，旧记录继续显示保存时的规则快照；新记录使用修改后的规则。

## 4. 当前不做

- 多人协作、员工端、账号、权限、网络和云同步；
- 自动读取日报、批量历史迁移、OCR 和 AI API；
- 绩效、质量、难度、工时等额外系数；
- 自动重复删除、复杂异常检测和仪表盘；
- 英文界面切换和安装程序。
