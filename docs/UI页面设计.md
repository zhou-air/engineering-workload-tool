# UI 页面设计

## 1. 主界面

使用 Windows 原生 Tk/ttk 控件，主窗口包含四个标签：工作录入、历史记录、导出、设置。界面以紧凑、清楚和少弹窗为主，不设置首页仪表盘。

## 2. 工作录入

固定顺序：日期 → 人员 → 项目 → 模块 → 工作类别 → 具体规则 → 数量 → 自动预览 → 备注 → 保存。

- 模块、类别、子类型三级级联；
- 数量字段名称和单位随规则变化；
- 规则 ID、标准化数量和工作量只读；
- 撬装设备和整体修改显示“本次基准分”；
- 建筑/结构输入“人工确认的标准化数量”；
- M2-04 输入“人工确认的关联管道建模工作量”；
- 人工判断规则必须填写备注依据；
- 保存成功只更新页面状态文字，不弹出阻塞窗口；
- 当前日期、人员和项目在连续录入期间保留，数量和备注清空。

## 3. 历史记录

- 支持开始/结束日期、人员、项目、模块筛选；
- 默认只显示有效记录，可选择包含作废记录；
- 编辑时明确提示会按当前规则重建快照；
- 作废需要原因和二次确认，不物理删除。

## 4. 导出

- 按日期导出工作量明细；
- 按月导出明细、人员汇总、项目汇总、小组汇总；
- AI 数据导出为四个 CSV 和一个 `summary.json`；
- Excel 有表头、筛选、冻结首行、合理列宽和数值格式。

## 5. 设置

人员、小组、项目和规则均支持查看、新增、编辑、启用和停用。新增项目保存后刷新全部下拉框。设置页提供 SQLite 数据库备份。

## 6. 后续英文版

数据库规则已保留英文模块、类别、子类型、显示名和单位字段；主导航文字已有独立语言资源入口。V0.1 不显示语言切换。
