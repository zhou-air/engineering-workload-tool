# 规则字段模型

## 1. 字段

| 字段 | 含义 |
|---|---|
| rule_code | 唯一的可执行子规则 ID；单一原编码也增加 `-A` 后缀 |
| module / category / subtype | 中文三级级联选择 |
| display_name | 历史记录和导出中的工作名称 |
| input_label / input_unit | 用户实际输入的业务量及单位 |
| unit | 定额计算使用的标准单位 |
| base_score | 固定基准分；“根据实际情况确定”时为空 |
| quantity_mode | 标准化数量或特殊计算方式 |
| requires_basis | 保存时是否必须填写人工确认依据 |
| active | 新录入是否可选择；停用不影响历史 |

计算方式：

- `AUTO_1TO1`：标准化数量 = 实际数量；
- `AUTO_DIV100`：标准化数量 = 实际长度 ÷ 100；
- `MANUAL_STANDARDIZED`：用户直接填写经人工确认的标准化数量；
- `MANUAL_BASE_SCORE`：用户填写实际数量和本次基准分；
- `LINKED_WORKLOAD`：用户填写经人工确认的关联工作量；
- `DISABLED`：没有当前可执行计分方式。
